# Readme

## The hell is this?

This is a vibecoded fork of headshot2017's Supertux Milestone 1 port to the Sega Dreamcast console adding support for GLdc and a brand-new low-level PVR renderer. It also has a niftly 50/60Hz switch in the settings. Will not be updated much in the future due to usage of LLMs.

## But why?

To see a 2D game run on a 3D console at a reasonable framerate.
